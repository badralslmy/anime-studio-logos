# anime-studio-logos

Public SVG asset repository for jsDelivr.

## jsDelivr usage

Use the raw file path through jsDelivr:

```text
https://cdn.jsdelivr.net/gh/badralslmy/anime-studio-logos@main/<filename>.svg
```

Example:

```text
https://cdn.jsdelivr.net/gh/badralslmy/anime-studio-logos@main/Studio_Ghibli.svg
```

## Files

All SVG files in this repository are intended to be served directly via CDN.
